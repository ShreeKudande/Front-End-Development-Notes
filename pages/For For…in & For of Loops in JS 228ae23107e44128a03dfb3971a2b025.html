For/For…in & For...of Loops in JS

For Loop

A for loop is a control flow statement that allows you to repeatedly execute a block of code based on a specified condition. It's commonly used when you know in advance the number of times you want to iterate over a block of code.

Here's the basic syntax of a for loop in JavaScript:

for (initialization; condition; increment) {
  // code to be executed
}

Now, let's break down the different parts of the for loop:

  1. Initialization: This part is used to initialize a counter variable or variables. It typically sets the initial value of a variable that will be used to control the loop. For example, let i = 0 initializes a variable i with the value 0.
  1. Condition: This part is a condition that is checked before each iteration of the loop. If the condition evaluates to true, the loop will continue executing. If it evaluates to false, the loop will terminate. For example, i < 5 checks if the value of i is less than 5.
  1. Increment: This part is executed after each iteration of the loop. It updates the value of the counter variable. It can be used to increment or decrement the variable by a specific value. For example, i++ increments the value of i by 1 after each iteration.
  1. Code to be executed: This is the block of code that will be executed repeatedly as long as the condition is true. It can contain any valid JavaScript statements or code blocks.

Here's a simple example that demonstrates how a for loop works:

for (let i = 0; i < 5; i++) {
  console.log("Iteration:", i);
}

In this example, the loop will iterate 5 times because the condition i < 5 is true initially and after each iteration, until i becomes 5. The code inside the loop will be executed on each iteration, printing the value of i to the console. The output will be:

/*** * Console * ***/
Iteration: 0
Iteration: 1
Iteration: 2
Iteration: 3
Iteration: 4

That's the basic concept of a for loop in JavaScript. It allows you to repeat a block of code for a specific number of times, based on the initialization, condition, and increment parts of the loop.

For…in loop

Let's start with the for-in loop. Imagine you have a basket filled with different fruits, and you want to go through each fruit and check its color. We can use the for-in loop to accomplish that.

const fruitBasket = {
  apple: "red",
  banana: "yellow",
  orange: "orange"
};

for (let fruit in fruitBasket) {
  console.log(fruit + " is " + fruitBasket[fruit]);
}

In this example, we have a fruitBasket object that represents a basket with different fruits. Each fruit is associated with a color. The for-in loop allows us to iterate over each fruit in the fruitBasket object. Inside the loop, we use the fruit variable to access the name of each fruit, and fruitBasket[fruit] to access its corresponding color. The loop will go through each fruit in the fruitBasket and print out its name and color.

Here's the output you would see:

/*** * Console * ***/
apple is red
banana is yellow
orange is orange

I hope this example clarifies how the for-in loop works with objects.

We can call the key value using any name!!!

Yes, that's correct! In the example you provided, the variable fruit is just a placeholder name that represents each key or property in the fruitBasket object as you iterate over them using the for-in loop.

You can actually use any valid variable name instead of fruit. For example, you could use key instead of fruit:

for (let key in fruitBasket) {
  console.log(key + " is " + fruitBasket[key]);
}

Or you could use property instead of fruit:

for (let property in fruitBasket) {
  console.log(property + " is " + fruitBasket[property]);
}

The important thing is that the variable you choose (whether it's fruit, key, property, or any other name) represents each key or property in the object during each iteration of the loop. You can then use that variable to access the corresponding value using bracket notation (fruitBasket[key], fruitBasket[property], etc.).

So, feel free to use any valid variable name that makes sense to you and helps you understand the code better.

I hope this clarifies the usage of variable names in the for-in loop!

For…of loop

Now, let's move on to the for-of loop. Imagine you have a line of friends waiting to go on a roller coaster ride, and you want to call each friend's name to join. The for-of loop helps you do that with arrays and other iterable objects in JavaScript.

Here's an example:

const friends = ["Alice", "Bob", "Charlie", "Dave"];

for (let friend of friends) {
  console.log(friend); // Prints the name of each friend
}
/*Iterate meaning:- Repeat something*/

In this example, we have an array called friends that contains different names. The for-of loop allows us to iterate over each element in the friends array. Inside the loop, we can access each friend's name using the friend variable. The loop will go through each friend in the array and perform the specified actions.

Key Differences in For…in & For…of Loop

Google

What is the difference between for in and for of loop?

Ans- Both for..in and for..of are looping constructs which are used to iterate over data structures. The only difference between them is the entities they iterate over: for..in iterates over all enumerable property keys of an object. for..of iterates over the values of an iterable object.

The key difference between the for-in and for-of loops is the way they iterate over elements.

The for-in loop is used to iterate over the properties or keys of an object. It allows you to access each property name or key one at a time. It's commonly used with objects.

On the other hand, the for-of loop is used to iterate over the elements of an iterable object such as an array, string, or other collection. It allows you to access each element directly without needing to access the index. It's commonly used with arrays and similar data structures.

So, in summary:

  • The for-in loop is used to iterate over the properties of an object.
  • The for-of loop is used to iterate over the elements of an array or other iterable objects.

Remember that the for-in loop is best suited for objects, while the for-of loop is best suited for arrays and other iterable objects.
