Callbacks in JS…

Q. Explain me callbacks in JS, assuming I am a child and explain how to use it?

Ans:- Callbacks in JavaScript are functions that are passed as arguments to other functions. They are commonly used in asynchronous operations to handle the result of an operation once it is completed. Think of a callback as a way to tell a function what to do when a certain task is finished.

To explain callbacks to you as a child, let's imagine a scenario where you are playing a game with your friends, and you want to perform some actions when the game is over.

Here's a simple example:

function playGame(gameName, callback) {
  // Simulating the game by printing a message
  console.log(`Playing ${gameName}...`);

  // Simulating the game duration
  setTimeout(function () {
    // Game over! Call the callback function
    callback();
  }, 3000); // Wait for 3 seconds
}

function celebrate() {
  console.log("Yay! We won the game!");
  // You can do more actions here, like dancing or cheering
}

// Let's play a game and celebrate when it's over
playGame("Super Mario", celebrate);

In this example, the playGame function takes two parameters: gameName and callback. The gameName parameter represents the name of the game you're playing, and the callback parameter represents the function that will be called when the game is over.

Inside the playGame function, we simulate playing the game by printing a message to the console. Then, we use the setTimeout function to wait for 3 seconds (simulating the game duration). After 3 seconds, the game is considered over, and we call the callback function.

The celebrate function is defined separately. It represents the action you want to perform when the game is over. In this case, it prints a celebratory message to the console.

When we call playGame("Super Mario", celebrate), we pass "Super Mario" as the game name and celebrate as the callback function. So, when the game is over, the celebrate function will be executed, and you will see the message "Yay! We won the game!" in the console.

Callbacks are a powerful concept in JavaScript because they allow you to define different actions to be performed after an asynchronous operation completes. This way, you can have more control over the flow of your program and handle the results appropriately.

Q. why my code is not working try to solve the error:-

function check(sec, callback){
  setTimeout(function() {
    let i;
     for(i=0; i<100; i++) {
      console.log(i);
     } callback();
    }, sec)
}

function run(a,b) {
  console.log(a+b);
}

check(5000, run(5,5))

Ans:- The issue with your code lies in the way you are passing the callback function to the check function. Instead of passing the function itself, you are immediately executing the run(5, 5) function and passing its result as the callback.

To fix the error and make your code work, you need to pass the run function as a callback without executing it immediately. Here's the corrected code:

function check(sec, callback) {
  setTimeout(function() {
    let i;
    for (i = 0; i < 10; i++) {
      console.log(i);
    }
    callback();
  }, sec);
}

function run(a, b) {
  console.log(a + b);
}

check(5000, function() {
  run(5, 5);
});

In the corrected code, instead of directly calling run(5, 5), we create an anonymous function and pass it as the callback to check(5000, ...).

Now, when the timeout expires after 5000 milliseconds (5 seconds), the loop inside check will run, printing numbers from 0 to 9. After that, the anonymous function will be executed, which calls run(5, 5), resulting in the sum 10 being logged to the console.

By using the anonymous function as the callback, we ensure that run(5, 5) is executed at the appropriate time, after the loop inside check has completed.
